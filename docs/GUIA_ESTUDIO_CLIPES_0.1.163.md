# Estúdio de Cenas — uso rápido (0.1.163)

1. Em **Estúdio de Cenas → Novo projeto**, informe um nome (ex.: *Abacate e Banana*).
2. Escreva uma ideia em poucas palavras (ex.: *Abacate e banana brigam na cozinha*) e escolha Animação 3D, 2D ou Realista.
3. Toque em **Criar minhas cenas** para começar manualmente. **Pedir ajuda ao Gemini com a história** é opcional e exige confirmação.
4. Em **Nova cena**, descreva uma ação: *Abacate e banana se olham sem falar*. Salve. Uma cena corresponde a **uma geração de vídeo** no Google Flow.
5. Crie a Cena 2: *A câmera foca no abacate irritado; ele gesticula*. Toque em **Falas por personagem** para definir **Abacate: “Não gosto de vitamina com banana!”**. Câmera e sons são opcionais.
6. Use **Importar imagem** para selecionar imagem/quadro de referência, ou **Gerar imagem** para solicitar uma imagem 9:16 pelo Gemini após escolher um modelo e confirmar. Imagens não são vídeos.
7. Use **Preparar prompt sem IA** para criar um prompt em inglês a partir dos seus dados, ou **Aprimorar este clipe com Gemini** no menu para revisar uma sugestão da IA.
8. Repita para a Cena 3 (banana responde), sempre usando referências e último quadro quando disponíveis. Copie um prompt por vez para o Flow.
9. Em **Exportar para Flow**, copie prompts, compartilhe imagens ou exporte ZIP. Depois, vincule os vídeos gerados em cada cena para organizar a montagem.

**Chaves Gemini**: seleção manual em Configurações vale para novos pedidos do aplicativo inteiro. Troca automática é opt-in, só em HTTP 429 entre projetos Google distintos; não será feita em 503, timeouts ou cobranças incertas. Se uma chave não oferecer o modelo escolhido, consulte os modelos disponíveis novamente.
